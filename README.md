# LocalVendors

![LocalVendors Logo](https://via.placeholder.com/150)

## 📌 Description
LocalVendors is a product listing app designed to help street vendors showcase their products online for free. It provides secure authentication and authorization with an admin panel to manage vendor products, update images, and modify prices. The app ensures security with email OTP verification and offers a responsive mobile interface for an enhanced user experience.

## 🚀 Features
- 🛡️ **Secure Authentication & Authorization** (JWT & OTP Verification)
- 🏪 **Admin Panel** for managing vendor products
- 📸 **Image & Price Updates** for vendors
- 📢 **Free Advertising Platform** for street vendors
- 📱 **Mobile-Friendly UI** built using Flutter
- 🌐 **User-Friendly Product Sharing**
